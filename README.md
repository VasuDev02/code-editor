# Code Editor Web Application

A lightweight **browser-based code editor** built using **React**.  
This project provides a simple interface where users can write and edit code directly in the browser.

The application is deployed using **GitHub Pages** and runs completely on the client side.

---

## 🚀 Features

- Browser-based code editor
- Fast and responsive interface
- Built using React
- Lightweight and easy to use
- Runs directly in modern browsers
- Static deployment with GitHub Pages

---

## 🛠 Tech Stack

### Frontend
- React
- JavaScript
- HTML5
- CSS3

### Deployment
- GitHub Pages
